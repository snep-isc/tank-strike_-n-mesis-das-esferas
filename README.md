# Tank Strike - Nemesis Das Esferas

Jogo Tank Strike - Nemesis das Esferas, criado com TypeScript e interface web.

## Visao geral

Este repositorio faz parte dos projetos da conta **snep-isc**. A ideia e manter o codigo organizado, documentado e facil de continuar evoluindo.

## Funcionalidades

- Gameplay em navegador
- Componentes organizados para tela, estado e servicos
- Base pronta para expandir fases, inimigos e mecanicas

## Tecnologias

- TypeScript
- React
- Vite
- HTML
- CSS
- Tailwind CSS

## Como usar

Clone o repositorio:

``bash
git clone https://github.com/snep-isc/tank-strike_-n-mesis-das-esferas.git
cd tank-strike_-n-mesis-das-esferas
``

Comandos ou passos principais:

- `npm install`
- `npm run dev`
